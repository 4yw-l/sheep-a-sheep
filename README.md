# 羊了个羊（Sheep a Sheep）

一个用 **Vibe Coding** 实现的纯前端「三连消除」小游戏。零依赖、零构建，下载即玩。

## 玩法

- 点掉被遮挡的方块，凑齐 **3 个相同图标** 即可消除。
- 被上层压住的方块会变暗、暂时点不动。
- 7 格托盘满了还没凑齐三连就失败；全部消除即通关。
- 简单关卡通关后解锁 **困难关卡**。
- 内置道具：撤销、洗牌（各有限次），以及可开关的 Web Audio 背景音乐与音效。

## 技术说明

- 纯 `HTML` + `CSS` + `JS`，所有图标为内联 SVG，不依赖 emoji 字体或图片资源。
- 背景音乐 / 音效用 Web Audio API 实时合成，无需任何音频文件。
- 无构建步骤，无外部依赖，`git clone` 后直接用浏览器打开 `index.html` 即可运行。

## 本地运行

```bash
# 方式一：直接用浏览器打开
open index.html        # macOS
# 或双击 index.html

# 方式二：起一个本地静态服务器
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 部署

本项目是静态站点，可直接托管到任意静态平台：

- **Vercel**：导入仓库即自动识别为静态站点，`index.html` 为入口。
- **腾讯云 CloudBase 静态网站托管**：上传目录即可获得 `*.tcloudbaseapp.com` 域名。
- 也可通过 WorkBuddy「发布为应用」一键上线。
